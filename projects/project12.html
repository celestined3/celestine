Skills Used

Python · LaTeX · Microsoft Excel

Overview

I created a tool in Python that aids with solving mathematical problems involving matrices. Doing this allowed me to develop my Python programming skills, as well as learn how refining the problem's finite element mesh (matrix size) affects the accuracy of the solution and its related tolerances. This was a great way to become accustomed to using Python, since I was applying simple maths knowledge, it was easier to understand how the coding language worked.

Please feel free to reach out to me for the full code if you are interested in this tool.
