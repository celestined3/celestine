FRF Beam Analysis

Skills Used

MATLAB · Teamwork · Microsoft Excel · LaTeX

Overview

This project involved working with another engineer to analyse the Frequency Response Functions (FRFs) of a vibrating T-beam. I wrote a separate MATLAB script for both theoretical and experimental results, with the report mirroring the maths used in the code. We were able to predict the natural frequencies and mode shapes of the beam through a lumped-parameter analysis. This was a great way for me to acquire new skills in MATLAB which are highly applicable to industry.
