Wind Tunnel Automatic Test Rig DAS

Skills Used

Python · Microsoft OneNote · LaTeX · Avionics

Overview

This project focused on creating an advanced program to run an automated test sequence for a wind tunnel experiment. As well as setting up the hardware myself, I wrote the entire Python code used to run the Data Acquisition System from scratch and I have provided a user manual detailing all aspects of the DAS. This project really took me out of my comfort zone whilst dealing with the electronics but creating an instruction manual really forced me to understand each step of the process. Feel free to reach out to me if you are curious to see the full code.
