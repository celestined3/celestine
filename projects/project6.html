Albatross Flight Briefing Document

Overview

This is a briefing document for an unmanned RC model aircraft, intended to aid a novice pilot in preparing and flying it at Snowdonia airfield in Wales, United Kingdom. I got the chance to use the software Unity in great depth for this project and really enjoyed the game simulation aspect of it! A video of a flight test circuit I did on Unity is included on the last slide. This project broke down the different components of an aircraft and highlighted just how challenging it can be to achieve trimmed flight.
